# AI.EXE Private Finance Phase — Cost Breakdown and Scenarios

Prepared: **2026-08-10**

Purpose: written cost record for the signed private phase and planning ranges for client/caseworker discussion.

All amounts below are planning estimates in USD unless an invoice states otherwise. They are not investment-return projections.

## Signed one-time development allocation

| Work package | Amount |
|---|---:|
| Engineering stabilization | $200 |
| Windows packaging, hosted adapter/API, paper broker, confirmation gate and ledger | $150 |
| Release/acceptance testing and delivery documentation | $100 |
| Business plan and cost documentation | $50 |
| **Signed phase total** | **$500** |

## Ongoing operating scenarios

| Scenario | Assumptions | Estimated monthly cost |
|---|---|---:|
| Low | Local records and paper simulation; free/keyless quote sources used occasionally; no paid hosted provider | $0–$25 |
| Expected | One paid hosted-model subscription/API budget, normal private testing, keyless market quotes | $60–$100 |
| High test usage | Heavier hosted-model/API use, paid backup/storage or support tools, frequent testing | $150–$300 |

These ranges exclude taxes, legal advice, incorporation, accounting services, regulated broker/exchange fees, market-data licences, banking integrations, code signing certificates, hardware and public customer support.

## Separate future work

The following is not included in the signed $500 phase and requires a new estimate and written approval:

- Bundled Windows local model/runtime and offline hardware validation
- Public product preparation, EULA/privacy/refund/support terms and code signing
- Live broker or exchange integration
- Corporate bank/EFT integration
- KYC/AML, custody, regulated advice or money-transmission work
- Ongoing maintenance or service-level commitments

## Caseworker framing

The current phase is a capped private software-development and testing engagement. It does not hold customer funds, transmit bank transfers, execute live securities/crypto orders or promise earnings. The expected ongoing technology cost can remain below the client's stated $1,000 monthly cap, but any public or regulated financial product would require a separate legal, provider and security budget.
